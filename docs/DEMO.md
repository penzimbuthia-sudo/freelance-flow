# Demo script — about 2 minutes 50 seconds

Prepare first: restart the updated backend and keep Vite running; save the freelancer display name; prepare a fictional overdue request and a fresh USD 1.00 request due today; configure and smoke-test real Gemini and PayPal sandbox; have a separate Personal sandbox buyer ready privately. Keep an already-confirmed sandbox payment available if login takes too long. Turn off browser print Headers and footers to keep private URLs out of print output. Never show `.env`, keys, private payment-page URLs or buyer passwords on the recording. If live services are blocked, say so; never present fixtures as live results.

- **0:00–0:15 — Context.** Show dashboard totals. “Clear facts, a useful next step, and a human-reviewed message—not automatic reminders.”
- **0:15–0:40 — Explain this payment.** Open the prepared overdue request. Point to its Python-calculated overdue days and next action. Switch to the fresh due-today request to show the different guidance without claiming it is late.
- **0:40–1:05 — AI-assisted draft.** Generate guidance. Explain: “Gemini selects an approved wording style; the app supplies payment facts, the client greeting and my saved signature.” Edit a sentence, copy the edited text and copy the deterministic payment link separately. Nothing is sent.
- **1:05–1:55 — Sandbox and activity.** Open the fresh client page. If time allows, cancel once, refresh details to show the recorded cancellation and unpaid status, then retry. Approve privately with the sandbox buyer. Wait for server verification; do not skip it to fit the recording. If login runs long, switch transparently to the prepared existing confirmed payment.
- **1:55–2:20 — Confirmation and print.** Show sandbox label, service, paid amount, freelancer, confirmation time and capture reference. Select **Print confirmation** and show the clean print preview: no navigation, buttons or AI draft, and no tax-invoice claim.
- **2:20–2:40 — Persistence and thanks.** Refresh details/dashboard: the confirmation activity and paid totals persist. Generate a thank-you; paid requests do not suggest another payment reminder.
- **2:40–2:50 — Boundaries.** “Local single workspace, sandbox only, human review required. No automatic sending, invented delivery events or real-money payments.”

If checkout takes longer, use the clearly identified existing paid example rather than rushing verification or implying a new payment completed. Keep the recording under three minutes.
