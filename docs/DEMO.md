# Demo script — about 2 minutes 40 seconds

Prepare first: start both servers; save the chosen freelancer display name in a request's AI panel; configure and smoke-test real Gemini and PayPal sandbox; have the separate buyer login ready privately; use fictional information; close unrelated tabs. Never show `.env`, keys, or buyer passwords on the recording. If live services are blocked, explain that honestly rather than presenting fixtures as live output.

- **0:00–0:20 — Problem and overview.** “Freelance Flow helps freelancers turn completed work into a clear payment request, a thoughtful message, and a simple sandbox checkout. Sending always stays in the human's hands.” Show paid/outstanding/overdue on the dashboard.
- **0:20–0:45 — Save a request.** New Payment Request: Alex Demo, fictional website design, USD 50.00, future due date. Create. Show saved details and pending status.
- **0:45–1:10 — Real AI.** Show the saved freelancer display name, then generate a message with that exact name in the closing. Point to the real Gemini/model label. Edit a sentence, copy the draft, then copy the payment link. “Nothing was sent automatically.”
- **1:10–2:05 — Sandbox checkout.** Open the client page. Highlight the sandbox warning and USD amount. Approve using the separate sandbox buyer. Wait for confirmed capture. “The server—not the browser callback—checks the amount, currency, seller, and completed capture.”
- **2:05–2:30 — Persistence.** Return to dashboard, refresh status if necessary. Show paid increased, outstanding decreased, and paid survives refresh. Filter the request list to Paid.
- **2:30–2:40 — Boundaries.** “This is a local, single-workspace sandbox MVP with fictional data. It does not automatically send reminders, use real money, or claim to be a multi-user production service.”

If checkout takes longer, cut narration, not server verification. Keep the recording under three minutes.
